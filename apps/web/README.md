# web

Sitio público y panel de administración de SERENA (Next.js). Ver el [README principal](../../README.md) para instalar y correr el proyecto, y [`docs/`](../../docs/README.md) para el diseño.

- `pnpm dev` — servidor de desarrollo en http://localhost:3000
- `pnpm build` — build de producción
- `pnpm lint` — ESLint

Variables de entorno: copiar `.env.example` a `.env.local`.
