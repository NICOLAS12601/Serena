# api

API REST de SERENA (NestJS): horarios libres, reservas, pagos, emails y autenticación del panel. Ver el [README principal](../../README.md) para instalar y correr el proyecto, y [`docs/`](../../docs/README.md) para el diseño.

- `pnpm dev` — servidor con recarga automática en http://localhost:3001
- `pnpm build` — compila a `dist/`
- `pnpm lint` — oxlint
- `pnpm test` — tests con Vitest

Variables de entorno: copiar `.env.example` a `.env`.
